Supprimer le compte – Hively

État au : 8 août 2026

Si tu souhaites supprimer ton compte Hively et les données cloud associées, tu peux en faire la demande à tout moment par e-mail.

Comment demander la suppression

  1. 1 Envoie un e-mail à hively.support@proton.me avec l’objet Supprimer le compte – Hively.
  2. 2 Indique l’adresse e-mail avec laquelle tu t’es connecté·e dans l’application.
  3. 3 Tu recevras une confirmation dès que le compte et les données cloud auront été supprimés — au plus tard dans les 30 jours.
Envoyer l’e-mail de suppression du compte

Ce qui est supprimé

DonnéesSuppression
Compte (e-mail, hash du mot de passe) Entièrement supprimé
Données d’exploitation synchronisées dans le cloud Entièrement supprimées
Abonnement Hively Pro actif Est résilié ; les factures Stripe peuvent être conservées légalement
Important : Les données purement locales sur l’appareil ne sont pas concernées par la suppression du compte. Utilise dans l’app « Supprimer les données locales » ou désinstalle l’application.
