# Sign in with Google — Branding

Buttons are rendered in `src/googleSignInButton.js` to match
[Google Identity branding guidelines](https://developers.google.com/identity/branding-guidelines):

- Approved CTAs only: Sign in / Sign up / Continue with Google (localized)
- Light: `#FFFFFF` fill, `#747775` 1px stroke, `#1F1F1F` text, 14/20 Medium
- Dark: `#131314` fill, `#8E918F` 1px stroke, `#E3E3E3` text
- Multicolor Google “G” on a **white** icon background (required)
- Height 40px (Google large), full width for equal prominence with SIWA

Do not use monochrome G icons or non-approved button labels.
