# Android Play Store Internal Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a GitHub Actions pipeline that builds the Capacitor Android app and uploads it to the Google Play "internal testing" track, mirroring the existing iOS TestFlight pipeline.

**Architecture:** Add the Capacitor Android platform, wire Gradle release signing to a CI-injected keystore, add a Fastlane `android beta` lane that calls `supply` (Play Developer API upload), and a new `android-playtest.yml` workflow triggered by `android-v*` tags. Signing/API credentials live only as GitHub Actions secrets, decoded to disk at CI runtime and never committed.

**Tech Stack:** Capacitor 8, Gradle (Android Gradle Plugin via Capacitor template), Fastlane (`supply` action), GitHub Actions (`ubuntu-latest`), `gh` CLI, `gcloud` CLI.

## Global Constraints

- Package/application id must be `ch.hively.app` (matches iOS, from `capacitor.config.json`).
- Release track is **internal testing** only — no production/beta track config.
- No secret material (keystore, passwords, service-account JSON) is ever committed to the repo.
- Tag namespace for Android releases is `android-v*`, independent from `ios-v*`.
- CI runner is `ubuntu-latest` (no macOS needed for Android builds).
- Follow the existing iOS workflow's patterns where they apply: version derived from tag, build number derived from `GITHUB_RUN_NUMBER`, secrets decoded into temp files and cleaned up with `if: always()`.

### Task 2: Wire Gradle release signing to a CI-injected keystore

**Files:**
- Modify: `android/app/build.gradle` (add `signingConfigs.release`, wire it into `buildTypes.release`)
- Create: `android/keystore.properties.example`
- Modify: `android/.gitignore` (ignore `keystore.properties` and `*.jks`/`*.keystore`)

**Interfaces:**
- Consumes: nothing new.
- Produces: a `release` signing config that reads `android/keystore.properties` (a file that does not exist in the repo — Task 5's CI workflow writes it at runtime; Task 3 documents the local-equivalent for manual testing).

- [ ] **Step 1: Add the ignore rules**

Append to `android/.gitignore`:

```
# Release signing (written at CI/build time, never committed)
keystore.properties
*.jks
*.keystore
```

- [ ] **Step 2: Add the properties template**

Create `android/keystore.properties.example`:

```properties
storeFile=release.keystore
storePassword=CHANGE_ME
keyAlias=hively
keyPassword=CHANGE_ME
```

- [ ] **Step 3: Add the signing config to `android/app/build.gradle`**

Open `android/app/build.gradle`. Inside the top-level `android { ... }` block, immediately before the existing `buildTypes { ... }` block, add:

```groovy
    def keystorePropertiesFile = rootProject.file("keystore.properties")
    def keystoreProperties = new Properties()
    if (keystorePropertiesFile.exists()) {
        keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
    }

    signingConfigs {
        release {
            if (keystorePropertiesFile.exists()) {
                storeFile file(keystoreProperties['storeFile'])
                storePassword keystoreProperties['storePassword']
                keyAlias keystoreProperties['keyAlias']
                keyPassword keystoreProperties['keyPassword']
            }
        }
    }
```

Then, inside `buildTypes { release { ... } }`, add the signing config reference as the first line of that block:

```groovy
            signingConfig signingConfigs.release
```

- [ ] **Step 4: Verify the Gradle file still parses**

```bash
cd android && ./gradlew help && cd ..
```

Expected: exits 0 (Gradle successfully evaluates the build script; no `keystore.properties` exists yet locally so the release signing config is empty, which is fine — this step only checks syntax/evaluation, not a full release build).

- [ ] **Step 5: Commit**


### Task 4: Add the Fastlane Android lane

**Files:**
- Modify: `fastlane/Fastfile` (add `platform :android` block)
- Modify: `fastlane/Appfile` (add `json_key_file`/`package_name` for Android, guarded so it doesn't break the iOS lane)

**Interfaces:**
- Consumes: `android/keystore.properties` (written by CI before this lane runs, per Task 2), `ANDROID_VERSION_NAME`/`ANDROID_VERSION_CODE` env vars (set by Task 5's workflow), `GOOGLE_PLAY_JSON_KEY_PATH` env var (path to the decoded service-account JSON, set by Task 5's workflow).
- Produces: `android/app/build/outputs/bundle/release/app-release.aab`, uploaded to the Play internal track.

- [ ] **Step 1: Add Android app identifier to the Appfile**

Edit `fastlane/Appfile`. The file currently has only iOS config (`app_identifier`, `team_id`, `apple_id`). Fastlane's Appfile supports platform-scoped values — add at the end:

```ruby
for_platform :android do
  package_name("ch.hively.app")
  json_key_file(ENV["GOOGLE_PLAY_JSON_KEY_PATH"]) if ENV["GOOGLE_PLAY_JSON_KEY_PATH"]
end
```

- [ ] **Step 2: Add the Android platform block to the Fastfile**

Edit `fastlane/Fastfile`. After the closing `end` of the existing `platform :ios do ... end` block, append:

```ruby

platform :android do
  desc "Build the Android app and upload it to the Play Store internal testing track"
  lane :beta do
    gradle(
      task: "bundle",
      build_type: "Release",
      project_dir: "android/",
      properties: {
        "android.injected.version.code" => (ENV["ANDROID_VERSION_CODE"] || "1").to_i,
        "android.injected.version.name" => ENV["ANDROID_VERSION_NAME"] || "0.0.1"
      }
    )

    upload_to_play_store(
      track: "internal",
      aab: "android/app/build/outputs/bundle/release/app-release.aab",
      json_key: ENV["GOOGLE_PLAY_JSON_KEY_PATH"],
      package_name: "ch.hively.app",
      skip_upload_metadata: true,
      skip_upload_images: true,
      skip_upload_screenshots: true
    )
  end
end
```

`skip_upload_metadata`/`images`/`screenshots` are set because this pipeline only ships binaries — store listing content is managed manually in Play Console (per the design's scope boundary).

- [ ] **Step 3: Verify Fastlane loads both platforms without error**

```bash

```

Expected: output lists both `ios beta` and `android beta` with no Ruby syntax errors.

### Task 5: Add the GitHub Actions workflow

**Files:**
- Create: `.github/workflows/android-playtest.yml`

**Interfaces:**
- Consumes: secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` (Task 3), `PLAY_STORE_JSON_KEY_BASE64` (Task 6), the Fastlane `android beta` lane (Task 4).

- [ ] **Step 1: Write the workflow file**

Create `.github/workflows/android-playtest.yml`:

```yaml
name: Android Play Internal Test

on:
  workflow_dispatch:
  push:
    tags:
      - 'android-v*'

jobs:
  beta:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    env:
      VITE_SUPABASE_URL: ${{ secrets.VITE_SUPABASE_URL }}
      VITE_SUPABASE_ANON_KEY: ${{ secrets.VITE_SUPABASE_ANON_KEY }}
      GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
      ANDROID_KEYSTORE_PASSWORD: ${{ secrets.ANDROID_KEYSTORE_PASSWORD }}
      ANDROID_KEY_ALIAS: ${{ secrets.ANDROID_KEY_ALIAS }}
      ANDROID_KEY_PASSWORD: ${{ secrets.ANDROID_KEY_PASSWORD }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
          fetch-tags: true

      - name: Determine version number from latest android-v* tag
        run: |
          tag=$(git describe --tags --match 'android-v*' --abbrev=0 2>/dev/null || true)
          if [ -z "$tag" ]; then
            echo "Kein android-v*-Tag gefunden, breche ab." >&2
            exit 1
          fi
          version="${tag#android-v}"
          echo "Version aus Tag $tag: $version"
          echo "ANDROID_VERSION_NAME=$version" >> "$GITHUB_ENV"
          echo "ANDROID_VERSION_CODE=${{ github.run_number }}" >> "$GITHUB_ENV"

      - uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: npm

      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: '3.3'
          bundler-cache: true

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Install JS dependencies
        run: npm ci

      - name: Build web app
        run: npm run build

      - name: Sync Capacitor Android project
        run: npx cap sync android

      - name: Write keystore and Play service-account key to disk
        run: |
          echo "${{ secrets.ANDROID_KEYSTORE_BASE64 }}" | base64 -d > android/release.keystore
          echo "storeFile=release.keystore" > android/keystore.properties
          echo "storePassword=$ANDROID_KEYSTORE_PASSWORD" >> android/keystore.properties
          echo "keyAlias=$ANDROID_KEY_ALIAS" >> android/keystore.properties
          echo "keyPassword=$ANDROID_KEY_PASSWORD" >> android/keystore.properties
          echo "${{ secrets.PLAY_STORE_JSON_KEY_BASE64 }}" | base64 -d > /tmp/play-service-account.json
          echo "GOOGLE_PLAY_JSON_KEY_PATH=/tmp/play-service-account.json" >> "$GITHUB_ENV"

      - name: Build and upload to Play Store internal testing
        run: bundle exec fastlane android beta

      - name: Clean up signing/credential files
        if: always()
        run: |
          rm -f android/release.keystore android/keystore.properties /tmp/play-service-account.json
```

- [ ] **Step 2: Commit**

```bash
git add .github/workflows/android-playtest.yml
git commit -m "feat(ci): add Android Play Store internal testing workflow"
```
